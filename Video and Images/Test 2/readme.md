# Static Fire Test 02

This directory contains the post-test documentation and media for the second static fire test of the custom solid rocket motor. 

## Motor Specifications
* **Propellant:** KNSB (Meltcast)
* **Configuration:** Single-grain Bates (20.8 mm OD)
* **Casing:** 25 mm diameter
* **Thermal Management:** 3D Printed Polycarbonate (PC) liner

## Test 02 Media & Documentation
This iteration specifically focuses on post-test component degradation. The following files document the structural and thermal evaluation after firing:

* **Post-Test Breakdown:** 
  * `Casing post fire.jpg`
  * `Nozzle and Front Closure post fire.jpg`
  * `Nozzle post fire.jpg`
  * `PC liner post fire.jpg`

* **Static Fire Footage:** 
  * `Test 2 video.mp4` (Includes the complete video recording of the live static fire on the test stand).

## Test Objectives & Observations
Building upon the baseline established in Test 01, this firing continued to evaluate internal ballistics and the structural safety of the motor components. The post-fire media specifically highlights the survivability of the 3D-printed PC thermal liner and assesses thermal soak-back wear on the aluminum casing, closures, and nozzle.
